### Animated Transitions

Unfortunately, if you're using React Router v6, there's not currently a great story for adding animated transitions to your app. They're aware and are ["going to have an animation API in v6"](https://github.com/remix-run/react-router/issues/7117#issuecomment-949096628) – though not sure when that's planned to be released.

Once it's released, we'll update this post.

If you're using another version of React Router, check out one of the following posts.

* [Animated Transitions with React Router v4](https://fireship.dev/c/react-router-v4/react-router-v4-animated-transitions)
* [Animated Transitions with React Router v5](https://fireship.dev/c/react-router-v5/react-router-v4-animated-transitions)
